# ephemeral_bloc example

A runnable Flutter application demonstrating typed one-shot UI actions,
provider-based listening, `EphemeralBlocConsumer`, and safe handling of an
asynchronous confirmation dialog.

From the repository root:

```shell
cd example
flutter pub get
flutter run
```

The generated project includes Android, iOS, Linux, macOS, Web, and Windows
runners. The platforms available to `flutter run` depend on the host operating
system and installed toolchains.
